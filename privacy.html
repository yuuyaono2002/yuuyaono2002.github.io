01

対象となるアプリと利用者

LGR Localは、管理者本人がWindows PCで利用する株式調査・記録用のデスクトップツールです。本ポリシーは、LGR LocalのGoogle連携・保存処理と、その機能を説明する本サイトに適用します。一般向けの登録・配布サービスや、自動売買サービスではありません。

Google、GitHub、市場データサービス、または利用者が別途使用するバックアップ・サポートサービスの処理については、それぞれの規約・ポリシーも適用されます。

02

アクセス・保存する情報

情報の種類主な内容・取扱い
Googleアカウント情報Drive APIが返すメールアドレスを、接続先アカウントの確認に使用します。確認結果をPC内に記録します。Googleのパスワードは取得しません。
Google認証情報アクセストークン・更新用トークン、およびOAuthクライアント設定を接続に使用します。トークンはWindowsのユーザー単位の保護機能で暗号化し、PC内に保存します。
Driveのメタデータアクセスを許可されたフォルダー・ファイルのID、名前、形式、サイズ、共有状態、権限情報、アプリ用管理情報などを確認します。保存履歴や照合情報をPC内に記録します。
保存対象のExcel利用者が保存対象とした調査・計算結果・メモ等の内容を含むExcelを、本人のDriveへ送信します。保存後は対象ファイルの内容を読み戻し、元の内容との一致を確認します。
ローカルの調査データ・処理記録入力データ、調査メモ、履歴、取得済みの市場・財務情報、処理日時、成否、ファイル照合値をPC内に保持します。現在のDrive保存処理はExcelを対象とし、認証ファイルやデータベース、内部ログをアップロードしません。

Googleから要求する権限は https://www.googleapis.com/auth/drive.file のみです。現在の処理では、アプリが作成した専用フォルダーと対象Excelを扱います。Drive全体を一覧・収集する権限や、Gmail・連絡先・カレンダーを読む権限は要求しません。

03

情報を使う目的

情報は、意図したGoogleアカウントと保存先の照合、専用フォルダーの作成・確認、Excelの保存、重複保存の防止、保存後の読戻し検証、処理状況と障害の確認のために使用します。ローカルの調査データは、利用者の調査・計算・記録のために使用します。

Google連携は、利用者がGoogleの認証画面で許可した後に行います。説明サイトを閲覧するだけで、PC内のファイルやGoogle Driveへアクセスすることはありません。

04

保存場所と保護

調査データ、生成ファイル、処理履歴は利用者のPC内に保存します。Googleへの認証トークンは、WindowsのDPAPIを使い、同じWindowsユーザーを前提とする方式で暗号化して保存します。通信にはHTTPSを使用し、認証トークンの値を通常の処理ログへ出力しません。

OAuthクライアント設定JSON、調査データ、Excelまで、すべてをアプリ独自に暗号化しているわけではありません。PCのアクセス管理、ディスク暗号化、バックアップの保護も必要です。認証情報は、公開リポジトリやクラウド同期フォルダーへ置かないでください。

Driveへの保存は、アプリが作成した本人所有の非共有フォルダーを確認してから行い、既存ファイルの共有設定を拡大しません。利用者が後からGoogle Drive上で共有設定を変えた場合や、PCの同期・バックアップを別に設定した場合、その設定に従ってコピーや共有が生じることがあります。

05

外部への送信・第三者による処理

Googleには、認証に必要な情報、保存先・対象ファイルの情報、保存するExcelの内容を送信します。Googleによる取扱いはGoogleプライバシーポリシーに従います。市場データサービスへの通信では、取得対象のコード・期間などを送ります。Googleの認証トークンやDriveから取得したファイルを、市場データサービスへ送信する機能はありません。

本アプリは、Googleから取得した情報をGitHub Pages、広告事業者、データ販売業者、生成AIサービスへ自動送信しません。GitHub Pagesに掲載するのは、アプリの説明と本ポリシーです。

利用者が別途サポートや遠隔保守を依頼する場合は、対象の情報と目的を示し、利用者の明示的な同意の範囲で扱います。認証トークンや認証コードそのものを、チャット・公開の問い合わせ・ログへ貼り付けることは求めません。

06

Googleユーザーデータの利用を限定します

LGR LocalによるGoogle APIから取得した情報の利用および他のアプリへの移転は、Limited Useの要件を含むGoogle API Services User Data Policyと、適用されるGoogle Workspace user data and developer policyに従います。

Googleから取得した情報を、販売、広告配信・追跡、信用判断・融資判断、汎用AI・機械学習モデルの学習のために使用または提供しません。人によるアクセスや他者への移転は、利用者が明示的に同意した機能提供・サポート、必要なセキュリティ対応、法令への対応など、Googleの該当ポリシーで認められる範囲に限定します。

07

保持期間

調査履歴と出力ファイルは、利用者が削除するまで保持する運用です。現在、自動的な一定日数での削除は行いません。認証情報は、連携の利用中はPC内に保存され、無効化・期限切れになったファイルも、利用者が削除するまで残る場合があります。

利用を停止しても、過去のローカルファイル、Drive内のExcel、別途作成したバックアップは自動では削除されません。GoogleやGitHub側のログ・バックアップ等には、それぞれの保持方針が適用されます。

08

連携の解除とデータの削除

Googleへのアクセスは、Googleアカウントの接続管理でLGR Localの接続を選び、許可を取り消すことができます。アプリ内で一括削除を実行する機能ではありません。

以後の処理を止めるには、PC上の定期タスクを無効にし、動作中のLGRを終了します。そのうえで、不要になった認証情報、ローカルの調査データ・出力・バックアップを、利用者がPC上で削除します。Driveの保存ファイルはGoogle Drive上で削除し、完全に削除する場合はゴミ箱も確認します。

接続の解除と、保存済みファイルの削除は別の操作です。削除前に必要な記録を確認してください。利用者が他者へ渡したコピーや、別の同期・バックアップに残るコピーは、この操作だけでは消えません。

09

この説明サイトの閲覧

本サイトには、管理者が追加する広告、アクセス解析、ログインフォーム、Cookieを使う追跡機能、外部の埋込みコンテンツを設けません。ただし、公開先のGitHub Pagesは、サイト訪問時のIPアドレスをセキュリティ目的で記録すると説明しています。したがって、「閲覧時の情報が一切記録されない」とは扱いません。

GitHubによる取扱いは、GitHub Pagesのデータ収集に関する説明とGitHubプライバシー声明を確認してください。外部リンクを開いた先の情報の扱いは、そのサイトの方針に従います。

10

ポリシーの変更

機能や情報の扱いを変更する場合は、本ページを改訂して更新日を示します。Googleから新たな情報を取得する、利用目的を広げる、または別の提供先へ移転する変更については、必要な説明と利用者の同意を得る前に実行しません。
